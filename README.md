# 清明祭祖 · 线上祭祖体验

一个清明祭祖的沉浸式网页作品。七节仪程，从设位到辞神，一头一尾都是火。

## 它是什么

- **旧火封面** → 点击入祭，火灭（禁火）→ 七节仪程 → 新火落幅（改火）
- 七节：设位 · 迎神 · 三献 · 读祝 · 侑食 · 阖门 · 辞神
- 每节都有引文与出处，来源是《礼记》《论语》《朱子家礼》

## 技术特征

| | |
|---|---|
| 零外部依赖 | 没有 CDN、图片、音频文件，单个 HTML 文件即可运行 |
| 音频 | Web Audio 全程实时合成：磬与钟（多分音叠加 + 指数衰减），加一层背景音（棕噪底床 + 低频持续音 + 羽调五声的稀疏琴音）。代码里没有一行音频资源 |
| 粒子 | Canvas 单循环渲染香烟、蒸汽、纸灰、浮尘四类粒子，共用一套更新器 |
| 状态机 | 七节仪程是数据驱动的 `STEPS` 数组，改流程只改数据不改逻辑 |
| 祭帖 | 运行时用 Canvas 现画 PNG，含干支纪年，可下载 |

## 本地运行

直接双击 `index.html` 即可。需要共享给同一 WiFi 下的人时，在该目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://<你的内网IP>:8080/`。

## 浏览器要求

桌面 Chrome / Edge，或手机浏览器（已做竖屏适配，触控热区 ≥44px）。声音需要先有一次点击才会解锁。
